# QuizFunny

Ελληνικό παιχνίδι γνώσεων με 15 ερωτήσεις, 4 επιλογές, κλίμακα εικονικών επάθλων έως 1.000.000 €, τέσσερις βοήθειες, προαιρετικό χρονόμετρο, ηχητικά εφέ, στατιστικά και αυτόματη αποθήκευση.

## Δημοσίευση

Settings → Pages → Source: **GitHub Actions**. Το workflow αναλαμβάνει τη δημοσίευση από τον κλάδο main.

## Τρέχουσα έκδοση

Περιλαμβάνει 50 επιμελημένες ελληνικές ερωτήσεις κατανεμημένες σε 15 επίπεδα, όχι ακόμη 1.000. Η επιλογή ερωτήσεων είναι τυχαία ανά επίπεδο. Οι βοήθειες κοινού και φίλου είναι προσομοιώσεις. Τα χρήματα είναι εικονικά. Απαιτείται δοκιμή σε browser/κινητό πριν θεωρηθεί πλήρως ελεγμένο.
